# EstadoVacio

Estado vacío amable: ilustración plana simple, una frase que dice qué pasa y la acción para empezar.

- Título que describe («Todavía no hay pacientes»), texto que orienta, una sola acción primaria («Agregá el primero»).
- Para «sin resultados» de un filtro, sin ilustración (`ilustracion={false}`) y con «Limpiar filtros».
- La ilustración es geométrica en la paleta; el diente-mascota del sello solo en momentos puntuales.
