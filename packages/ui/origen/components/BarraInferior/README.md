# BarraInferior

Navegación del celular: cinco destinos fijos al pie — Inicio, Agenda, Pacientes, Caja y Más.

- «Más» abre una HojaInferior con el resto de módulos (Odontología, Personal, Inventario, Sonrisa Comunitaria, Estadísticas), el selector ES · GN y los ajustes.
- Ícono + texto siempre; el activo con píldora turquesa-suave.
- `fija` la pega al pie respetando el área segura; dejá `barra-inferior` de margen inferior en el contenido.

El consumidor provee: `activo` y `rutas` u `onNavegar`.
