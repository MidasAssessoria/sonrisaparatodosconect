# TarjetaMetrica

Cifra clave con etiqueta y comparación con el período anterior, para Inicio, Caja y Estadísticas.

- Número en Fredoka 36px; etiqueta arriba en tinta-suave.
- El cambio lleva flecha + texto; el `tono` dice si es bueno (`exito`) o malo (`atencion`), no la dirección: más ausencias sube en coral.
- Todo número de ejemplo se marca como tal en la página (PieMaqueta).
