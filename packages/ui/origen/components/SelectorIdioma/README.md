# SelectorIdioma

Selector ES · GN de la interfaz, siempre visible: en la barra superior y en «Más» en el celular.

- Es un grupo de radio: cada opción anuncia «Español» o «Guaraní».
- Cambia la interfaz, no el idioma del paciente (eso es un Campo en la ficha: «Idioma del paciente»).
- El guaraní va en saludos y etiquetas simples («Mba'éichapa», «Aguyje»); lo que no tenga traducción validada se marca «traducción pendiente», no se inventa.

El consumidor provee: `valor` y `onCambio`.
