# Chip

Chip de estado: una o dos palabras, con ícono, en píldora. El mismo estado usa el mismo tono en todas las páginas.

| tono | estados |
| --- | --- |
| `exito` (turquesa) | Confirmado, Atendido, Aprobado, Pagado, Emitida, Sincronizado |
| `atencion` (coral) | Pendiente, Sin confirmar, Atrasado, Nivel bajo, Agotado, Con error, alergias |
| `progreso` (sol) | En curso, En sala, Pago parcial, Próximo a vencer, condiciones clínicas |
| `info` (cielo) | Agendado, Enviado, Propuesto, Seguimiento |
| `categoria` (uva) | Tipo de tratamiento, categoría de insumo |
| `familia` (rosa) | Pediátrico, Grupo familiar |
| `neutro` | Ausente, Cancelado, Inactivo, Borrador, Deshabilitado |

Nunca solo color: el texto dice el estado. No usar en la pantalla de odontograma tonos que se confundan con marcas clínicas.
