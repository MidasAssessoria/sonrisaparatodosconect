# Avatar

Iniciales en círculo, en lugar de foto, para pacientes y personal.

- Tono por defecto derivado del nombre (siempre el mismo para la misma persona), en pares -suave / -texto que pasan 4.5:1.
- `decorativo` cuando el nombre ya está escrito al lado; si no, el Avatar anuncia el nombre.
- Tamaños: sm 36 (listas densas, buscador), md 48 (tarjetas), lg 64 (cabecera de ficha).
