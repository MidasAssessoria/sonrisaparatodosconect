# Icono

Íconos lineales de trazo 2px con puntas redondeadas en caja de 24, que heredan el color del texto (`currentColor`).

- En la navegación siempre con etiqueta de texto. Solo ícono: el control lleva `aria-label`.
- Tamaños: 16 en chips, 18–20 en botones y campos, 22–24 en navegación, 32 en marcadores.
- Set propio del sistema (36 íconos, lista en `Conecta.Icono.nombres`). Para íconos que falten, usar Lucide con trazo 2 (mismo estilo) y agregarlos acá.
