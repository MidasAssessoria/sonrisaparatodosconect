# GraficoBarras

Gráfico de barras horizontales con etiquetas y valores escritos, y un botón «Ver como tabla» con los mismos datos.

- Series en turquesa, cielo, uva, rosa y sol, en ese orden; el valor siempre escrito al lado (la barra sola no basta).
- Nivel de inventario: una barra por insumo; «Nivel bajo» como Chip `atencion` debajo, no solo la barra coral.
- Nunca rojo ni azul clínicos en gráficos.

El consumidor provee: `titulo`, `datos` y `formato` para los valores.
