# AvisoExito

Aviso de que algo salió bien («Atención guardada», «Cobro registrado»), con la acción siguiente a mano.

- Título corto en pasado; texto con el dato que confirma (monto de ejemplo, paciente, hora).
- `accion`: lo que se suele hacer después («Imprimir comprobante», «Enviar por WhatsApp»).
- `flotante` en el celular, sobre la BarraInferior; se cierra solo a los 6 s solo si no tiene acción.
- Es el lugar del diente del sello en momentos puntuales, no en cada aviso.
