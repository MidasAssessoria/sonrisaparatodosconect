# AvisoConexion

Estado de conexión para Sonrisa Comunitaria y Odontología: lo cargado sin señal se guarda local y se sincroniza.

- `sin-conexion` (sol): «Sin conexión · se guardará y sincronizará», con la cuenta de registros pendientes.
- `sincronizando` (cielo) y `sincronizado` (turquesa), este último se oculta a los pocos segundos.
- Va arriba del formulario, no tapa campos. Nunca bloquea el registro.
